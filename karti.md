# Промты для генерации картинок по темам презентации

---

## Тема 1. Проактивное информирование администраций областей о мошеннических схемах при расходовании бюджетных средств

### Вариант 1 (метафоричный, иконографический)

```
Изображение в стиле плоской инфографики на тёмно-синем фоне. В центре — стилизованная карта центральной части России, на которой подсвечены три региона (Курская, Белгородская и Брянская области) красными метками-точками. От карты отходят три линии, ведущие к зданию администрации с колоннами (иконка). Над зданием — щит с галочкой, символизирующий защиту. Вокруг карты расположены иконки: кошелёк с исходящими стрелками (расходование средств), документ с предупреждением (восклицательный знак в треугольнике), банк. Цветовая гамма: тёмно-синий, белый, красный акцент. Без текста.
```

### Вариант 2 (сценка с персонажами)

```
Изображение в стиле корпоративной векторной иллюстрации. Слева — официальный человек в костюме (представитель администрации региона) за столом с документами, он удивлённо смотрит на стопку бумаг. Справа — сотрудник Банка в деловом костюме с папкой, который протягивает ему документ-предупреждение с красным восклицательным знаком. Между ними на столе — схематичное изображение денежных потоков: стрелки от бюджетного кошелька к сомнительным получателям, часть стрелок перечёркнута красным. На заднем плане — силуэт пострадавшего от обстрелов здания. Цвета: сдержанные корпоративные, синий и серый, с красными акцентами на элементах предупреждения. Без текста.
```

## Тема 2. Мошеннические действия клиентов при получении кредитов

### Вариант 1 (коллаж-схема из нескольких схем мошенничества)

```
Коллажная иллюстрация в стиле изометрической векторной графики на светло-сером фоне, разделённая на несколько визуальных блоков. Блок 1: множество рук, тянущихся к одному смартфону, на экране которого — стопка одинаковых кредитных заявок (массовая подача с одного устройства). Блок 2: дом, разделённый пунктирными линиями на части, у каждой части свой кадастровый номер-табличка (дробление объектов недвижимости). Блок 3: автомобиль с ценником и печатью «господдержка», рядом — рука, незаметно забирающая часть денег (автокредиты с господдержкой). Блок 4: человек в галстуке IT-специалиста держит поддельный документ с печатью (Ипотека для IT по фиктивным документам). Блок 5: пирамида из монет с надписью-иконкой (финансовая пирамида). Блок 6: человек, подающий в суд на банкротство, с чемоданом денег за спиной. Единая цветовая палитра: синий, оранжевый, белый. Без текста, только иконки.
```

### Вариант 2 (сценка — подача заявки и обнаружение мошенничества)

```
Изображение в стиле 2D-векторной иллюстрации. В центре — крупный смартфон, на экране которого отображена форма кредитной заявки с галочками «одобрено». Вокруг телефона — несколько одинаковых фигурок людей (заявок), стоящих в очереди, все держат идентичные документы. На заднем плане — офис банка, за столом сидит сотрудник Банка с лупой, рассматривающий документы; его брови нахмурены, рядом — монитор с красными предупреждающими значками. Над сценой — полупрозрачная схема-диаграмма со стрелками, ведущими от одного устройства к нескольким кредитам. Цвета: корпоративные синие и белые тона с красными акцентами на элементах тревоги. Без текста.
```

## Тема 3. Улучшение системы контроля за неправомерными действиями 3-их лиц (хищение средств клиентов и Банка)

### Вариант 1 (щит-защита, метафора)

```
Изображение в стиле 3D-векторной иллюстрации. В центре — крупный стилизованный щит с логотипом-замком (защита клиентов). Щит светится мягким синим светом. Перед щитом — три фигуры мошенников в тёмных капюшонах, которые пытаются дотянуться до банковских карт клиентов, но наталкиваются на невидимый барьер. За щитом — группа клиентов (обычных людей), которые чувствуют себя в безопасности. Между мошенниками и клиентами — поток цифровых данных и стрелок, часть которых блокирована красными крестиками. Внизу — иконка канала ЕРКЦ (монитор с перечёркнутой рукой). Цвета: синий (защита), красный (блокировка), серый (мошенники). Без текста.
```

### Вариант 2 (сценка с персонажами — клиент и мошенник)

```
Изображение в стиле плоской корпоративной иллюстрации. Слева — пожилой клиент с банковской картой в руках, он растерян и разговаривает по телефону; над его головой — облачко мысли с перечёркнутой картой и иконкой замка (карта заблокирована третьими лицами). Справа — фигура мошенника за компьютером в тёмной комнате, на экране — интерфейс канала ЕРКЦ с чужими данными клиента; рядом со столом — мешок с деньгами. В центре между ними — стена из пикселей/кубиков с символом замка (улучшенная система контроля), которая растёт и перекрывает путь от мошенника к клиенту. В нижнем правом углу — иконка телефона с пузырём «жалоба клиента». Цвета: синий, белый, тёмно-серый для мошенника, зелёные акценты на элементах защиты. Без текста.
```
